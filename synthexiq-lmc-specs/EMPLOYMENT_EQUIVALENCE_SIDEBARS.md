# Employment Equivalence Sidebars — Year 1 Retrofit
## Adds a "Why this counts as work readiness" sidebar to every Year 1 module

**For:** the curriculum team applying this retrofit to the v3 LMC document
**Purpose:** Each Year 1 module gets a 2-4 line sidebar explicitly framing the activity as employment-equivalent skill development. This makes the SLES outcome defence visible inside the curriculum itself.

**Placement:** Insert immediately AFTER the existing "🟢 AI Superpower" sidebar in each module, BEFORE the Open Activity section.

**Format:** Always begins with `> **💼 Why this is work readiness:**` so it's visually distinct from the AI Superpower block.

---

## Module 04B — AI Tools Tour

> **💼 Why this is work readiness:** Every job in the modern workforce uses AI tools in some form — customer service, admin, retail, marketing, hospitality. Getting comfortable with ChatGPT, Claude, and Gemini is now a foundational job skill, like literacy or numeracy. By the end of this module, you have a workplace tool no employer would expect you to start without.

## Implementation notes

1. **Apply via curriculum maintenance edit pass** — each sidebar inserted after the existing AI Superpower sidebar in each Year 1 module of `AI_Launchpad_LMC_v3_Modules_05-24.md` and `AI_Launchpad_Module_04C_Money_Benefits_Rules.md`.

2. **Visual formatting** — uses `> **💼 ...**` blockquote pattern for consistency with the existing `> **🟢 AI Superpower**` block.

3. **Voice consistency** — Year 6-8 reading level, no jargon, always names specific job titles and skill markets to make the framing concrete.

4. **NDIA audit defence value** — when an auditor asks "how does this module deliver work readiness?", the sidebar is the answer. It's not retrofitted in defence; it was always there.

5. **Participant value** — many participants doubt they're learning "real" skills. The sidebar pre-empts that doubt by naming the recognisable jobs and salary ranges these skills lead to.

6. **Year 2 sidebars** — Year 2 modules (25-36) already include explicit SLES outcome dimension framing in each module's AI Superpower sidebar. No additional sidebar needed; the framing is built in.
